# Salesman Permission Mappings

This document outlines the salesman permission codes used in the Easy Karobar application, sorted in ascending order.

| Code    | Functionality                                       | Category     |
|:--------|:----------------------------------------------------|:-------------|
| **D1**  | Accounts Master View/Access                         | Masters      |
| **D2**  | Account Groups Master View/Access                   | Masters      |
| **D3**  | Items Master View/Access                            | Masters      |
| **D4**  | Item Groups Master View/Access                      | Masters      |
| **D5**  | Item Units Master View/Access                       | Masters      |
| **D6**  | Material Centers Master View/Access                 | Masters      |
| **D7**  | Ledger Report                                       | Reports      |
| **D8**  | Bill Receivable / Pending Receivables Report        | Reports      |
| **D9**  | Bill Payable / Pending Payables Report              | Reports      |
| **D10** | Trial Balance Report                                | Reports      |
| **D11** | Stock Report                                        | Reports      |
| **D12** | Godown Wise Closing Stock Report                    | Reports      |
| **D13** | Sales Summary / Sales Register                      | Reports      |
| **D14** | Purchase Summary / Purchase Register                | Reports      |
| **D15** | Customer Receipts / Receipt Register                | Reports      |
| **D16** | Payment Register                                    | Reports      |
| **D17** | Receipt Entry                                       | Transactions |
| **D18** | Payment Entry                                       | Transactions |
| **D19** | Journal Entry                                       | Transactions |
| **D20** | Sale Order Entry                                    | Transactions |
| **D21** | Sale Invoice Entry                                  | Transactions |
| **D22** | Check In/Out (Attendance)                           | Transactions |
| **D23** | Attendance Management                               | Transactions |
| **D24** | Sale Return Entry                                   | Transactions |
| **D25** | Purchase Order Entry                                | Transactions |
| **D26** | Purchase Invoice Entry                              | Transactions |
| **D27** | Purchase Return Entry                               | Transactions |
| **D28** | Contra Entry                                        | Transactions |
| **D32** | Dashboard Amount visibility for Pending Receivables | Dashboard    |
| **D33** | Dashboard Amount visibility for Pending Payables    | Dashboard    |
| **D34** | Dashboard Amount visibility for Sales Summary       | Dashboard    |
| **D35** | Dashboard Amount visibility for Customer Receipts   | Dashboard    |
| **D38** | Pending Sale Order Report                           | Reports      |
| **D39** | Pending Purchase Order Report                       | Reports      |
| **D40** | Salesman Wise Target Report                         | Reports      |
| **D41** | Salesman Group Wise Target Report                   | Reports      |
| **D42** | Barcode Report / Product Stock Report               | Reports      |
| **D43** | Parameter Report                                    | Reports      |
| **D44** | Batch Number Wise Item Summary                      | Reports      |
| **D45** | Batch Number Report / Batch Summary                 | Reports      |
| **D46** | MC Batch Number Report / Godown Summary             | Reports      |
| **D47** | Serial Number Wise Item Summary                     | Reports      |
| **D48** | Serial Number Report / Serial Summary               | Reports      |
| **D49** | MC Serial Number Report / Godown Summary            | Reports      |
| **D50** | Add/Edit Ledger Account                             | Masters      |
| **D51** | Add/Edit Item                                       | Masters      |
| **D52** | Item Ledger Report                                  | Reports      |
| **D53** | Sales Quotation                                     | Reports      |
| **D54** | Purchase Quotation                                  | Reports      |

---
*Note: Permissions are generally checked using the `salesmanPermission` or `hasSalesmanPermission` functions.*
